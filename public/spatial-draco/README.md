# Draco browser decoders

Unmodified glTF decoder builds copied from Three.js 0.184.0,
`examples/jsm/libs/draco/gltf`. These decode Blender's Draco-compressed GLB meshes
locally, without fetching executable assets from an external CDN.

Upstream: https://github.com/google/draco
