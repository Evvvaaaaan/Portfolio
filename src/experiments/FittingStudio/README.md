# Fitting Atelier

Lab 경로: `/gallery/fitting-studio`

## 실행

프로젝트 루트에서 `npm run dev -- --host 127.0.0.1`을 실행합니다. 같은 컴퓨터에 설치되고 로그인된 Higgsfield CLI를 사용합니다. 화면의 CLI 상태 표시는 설치 여부이며, 계정 인증이나 크레딧 잔액을 보장하지 않습니다.

## 생성 흐름

1. 사용 권한이 있는 한 사람의 전신 사진과 원하는 의류의 제품 사진을 업로드합니다. 생성 전까지 이미지는 브라우저 안에만 있습니다.
2. 사진 전송 및 크레딧 사용에 동의한 후 착장 미리보기를 생성합니다. `product-photoshoot create --mode virtual_model_tryout`을 사용합니다.
3. 완전한 전신과 원하는 옷이 표현되었는지 직접 확인한 후 별도로 3D 생성을 누릅니다. `image_to_3d`로 텍스처가 있는 GLB를 요청합니다.
4. 인물 사진만으로 원본 착장의 3D 모델도 생성할 수 있습니다. 생성한 모델은 목록에서 전환·비교하고 GLB로 다운로드합니다.

각 생성은 별도 유료 작업이며 자동 재시도하지 않습니다. 페이지를 닫아도 이미 시작한 작업은 취소되지 않습니다. 시간 초과 시 중복 생성 전에 Higgsfield 작업 내역을 확인해야 합니다.

## 데모와 제한

- 기본 마네킹의 세 가지 옷, 색상, 회전, 확대, 조명, 와이어프레임, 화면 저장은 AI 없이 동작합니다. 기본 마네킹은 업로드 사진의 복원 결과가 아닙니다.
- 외부 파일을 참조하지 않는 GLB 2.0을 가져올 수 있습니다. 모델은 50MB 및 60만 삼각형 이하, 사진은 JPG/PNG/WebP 8MB 이하입니다.
- 생성 결과는 사람과 의상을 함께 재구성한 하나의 모델입니다. 독립된 의복 메시를 기존 신체에 물리적으로 입히는 시뮬레이터가 아닙니다. 신체 치수, 얼굴 동일성, 의복 사이즈, 뒷면과 원단의 실제 핏을 보장하지 않습니다.
- 생성 서버는 `dev/fittingService.js`의 **로컬 개발 전용** 연결입니다. 공개 빌드에서는 샘플 뷰어와 GLB 가져오기만 사용할 수 있습니다. 공개 AI 서비스에는 별도의 인증·과금·저장·작업 실행 서버가 필요하며 현재 배포하지 않았습니다.
- 로컬 연결은 루프백 주소, 동일 출처, 세션 토큰을 검사합니다. 자격 증명은 브라우저에 보내지 않습니다. 전송용 임시 파일은 작업 종료 시 삭제하고 결과는 제한된 프로세스 메모리에 보관합니다. 초기화는 로컬 결과만 지우며 Higgsfield 측 자료는 해당 서비스에서 관리해야 합니다.

## 검증

`npm test -- dev/fittingService.test.js src/experiments/FittingStudio/model.test.js`

`npm run test:e2e -- e2e/fitting-studio.spec.js`

자동화 테스트는 합성 이미지·모델과 모의 생성 응답을 사용합니다. 실제 인물 복원이나 의류 재현 품질을 입증하지 않으며 크레딧을 사용하지 않습니다. 실제 AI 결과는 사용자가 제공한 사진과 명시적 생성 실행으로 별도 검증해야 합니다.
