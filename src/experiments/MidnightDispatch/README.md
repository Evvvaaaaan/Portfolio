# Midnight Dispatch

끝없이 이어지는 탑다운 도시 게임입니다. 게임 내 현금은 의뢰와 숨겨진 현금 수집으로 얻습니다. 실제 결제는 없습니다.

- 네온 도심, 사막, 항구, 해안의 64개 블록과 14개 숨겨진 현금.
- 배달, 택시, 체크포인트 레이스, 무장 조직 소탕, 수배 탈출 의뢰.
- 권총·기관단총·산탄총과 탄약·방탄복 구매. 총기마다 피해량·사거리·발사 간격·탄창이 다릅니다.
- 기본 쿠페를 포함한 차량 10종. 배달 밴, 4륜구동, 스포츠카, 장갑차 등은 속도·가속·조향·장갑과 외형이 다릅니다.
- 차량 탈취, 수배 5단계, 경찰 추격, 수리·도색, 은신처 회복.
- 밤·노을·비 테마. 비가 오면 접지력이 줄어듭니다.

처음에는 노란 차에 탑승해 북쪽 야시장에 정차하세요. 첫 배달로 $600을 벌면 $450 권총을 살 수 있습니다. `G` 표식은 차고, `A` 표식은 무기점이며, 해당 고리 안에서 정차한 뒤 `B` 메뉴의 차고·무기점 탭에서 구매·장착할 수 있습니다. 새 의뢰 수락은 현재 의뢰를 교체합니다. 레이스는 출발 지점부터 제한 시간이 흐릅니다.

현금, 명성, 완료한 의뢰 수, 구매한 총·차량, 남은 탄약, 수집 기록과 테마는 현재 브라우저에 자동 저장됩니다. 다시 시작하면 은신처에서 다음 배달을 시작합니다. 활동 중인 의뢰·위치·수배·일시적인 체력과 방탄복은 저장하지 않습니다. 차량 파손·전투 패배·체포 후 회복 비용은 최대 $200이며 보유 장비는 유지됩니다.

| 조작 | 기능 |
| --- | --- |
| WASD / 방향키 | 이동·가속·조향 |
| Space | 달리기 / 핸드브레이크 |
| E | 차량 탑승·하차 / 가까운 상점 |
| F | 가까운 적 자동 조준 사격 |
| 마우스 클릭 유지 | 커서 방향으로 사격 |
| R / Q | 재장전 / 보유 무기 변경 |
| B / M | 의뢰·상점 / 지도와 길 안내 |
| Esc / P | 메뉴 닫기 / 일시 정지 |

모바일에서는 방향 패드와 화면 버튼을 사용합니다. 메뉴를 열거나 창을 벗어나면 시뮬레이션이 멈춥니다. 효과 줄이기는 빗줄기, 경광등 점멸, 카메라 효과를 줄입니다.

검증:

```sh
npx vitest run --config vitest.midnight.config.js
npm run test:e2e -- --config playwright.midnight.config.js
```

브라우저 테스트는 Chrome과 전용 로컬 포트 5184를 사용합니다. 개발 모드에서만 `?debug`로 상태·렌더링 지표·테스트용 위치 이동에 접근할 수 있습니다. 실사용 빌드에는 이 기능이 활성화되지 않습니다.
